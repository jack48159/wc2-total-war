# 对局案例：德国内战中的诱敌深入与核心区反击

日期：2026-10-04。对局：WC2-TKUJ-YYPR；关卡 battle_axis1_de（德国内战·德国B）。玩家指挥 de2（德国），Agent 指挥 de1（德意志第一装甲军团）。第8回合结束，玩家胜利。

## 玩家如何组织战场

以下战略意图来自玩家赛后明确说明，不能当作 Agent 在对局中提前知道的情报。

玩家开局收缩不是被迫退守，而是主动诱使 Agent 进攻。决战区域选在西部维也纳（1046）、林茨（1029）至东部三级工业区布拉迪斯拉发（1019）。主力能互相支援固守，附近有炮兵和部署资源，残兵可就地休整；对手则远离自身核心区域，炮兵仍在赶路。

玩家故意留下看似能切断东西部的通路，让 Agent 将穿插误判为突破。先锋进入后，玩家利用局部集中优势将其歼灭；按玩家复盘，这一阶段己方兵力与健康度损失很小。待对手主力被逐步蚕食后，玩家才展开反攻。这里不补写未经记录核实的具体交换比或每次攻击顺序。

## 实际回合过程

- 第1回合：Agent 以装甲9夺取维尔茨堡（1023），装甲11夺取美因茨（1024）；坦克10向莱比锡（171）、坦克12向多特蒙德（172）跟进。装甲1向科特布斯（150）移动。另在维尔茨堡部署炮兵27，柏林（149）部署炮兵28和坦克29。此时部队虽普遍前移，却尚未形成集中接战的火力。
- 第2回合：装甲9、坦克10和炮兵27集中在皮尔森南（1022），装甲11与坦克12进入雷根斯堡（1026），装甲1与坦克2进入布拉格东（167）。炮兵4仍在科特布斯，炮兵6在柏林，炮兵28在莱比锡。Agent 空袭林茨东（1030）并用装甲9攻击前排装甲21，将其降至18血；己方装甲9也降至54血。这次局部伤害没有破坏敌人的整体支援能力。
- 第3回合：最新视图中，皮尔森南的装甲9、坦克10和炮兵27均已消失。Agent 没有据此收缩进攻范围，而是让坦克29进入林茨东北（1021）、坦克2进入布尔诺西南（1020），装甲1经布拉迪斯拉发西（1032）深入布拉迪斯拉发东（1041）。西翼装甲11与步兵8又补入皮尔森南。穿插扩大了占地，也扩大了需要支援的范围。
- 第4回合：装甲1、装甲11、坦克2、坦克12和坦克29已不在己方可见单位中，主要装甲力量耗尽。炮兵4与28终于能从布拉格东、皮尔森（170）开火，无反击地分别打掉敌前排坦克28血、23血。11血步兵8沿空路经林茨东抵达维也纳南（1045）。这次占地没有阻止敌军继续集中反击。Agent 买入特种步兵35及步兵36，尝试填补防线。
- 第5回合：莱比锡、皮尔森已落入玩家手中，Agent 只剩步兵7、炮兵4、步兵32、特种步兵35。炮兵4继续压制林茨东北，残部后撤；柏林新部署装甲37并加防御战术。特种步兵35的接口显示攻击上下限为0，Agent 停止继续购买；这属于另待诊断的接口或兵种异常，不能代替战略复盘。
- 第6回合：汉堡（145）等地已失守，Agent 只剩柏林装甲37和步兵7；补入步兵39，装甲保持前排。玩家的反攻同时削减了 Agent 收入与合法部署地点。
- 第7回合：柏林失守，稳定度降至60；Agent 无剩余部队、无合法征兵地点，提交空行动。
- 第8回合：桥返回 gameOver，玩家胜利。此处回合间损失依据下一次可见快照与已执行命令确认，未逐条核实的敌方攻击过程不作补写。

## 真正的失误与应学到的判断

Agent 的问题不仅是炮兵慢，更是接受了玩家选择的战场：己方先锋离补兵区域远，敌方却能围绕核心城市、工业区和炮兵不断集中、恢复。东西通路被占领，不等于敌方部署与火力支援被切断。

第3回合前沿三单位堆叠损失后，应立即重新比较双方集中作战能力。此时继续分兵穿插，使剩余装甲进入新的局部劣势；第4回合炮兵虽开始有效输出，已经没有足够前排与占领部队利用战果。

可迁移的做法：防守方主动组织有补兵、休整和炮火支援的决战区域，诱敌脱节，先歼灭先锋，后反攻。进攻方则先确认支援能同时到场、占路真正限制敌军机动，再决定突破；不能以占地多、地理上切开东西联系证明进攻成功。若首都、资源和退路不允许收缩，也不能机械复制此局的诱敌打法。
