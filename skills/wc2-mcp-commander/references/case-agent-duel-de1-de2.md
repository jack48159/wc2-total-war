- de2 前四回合在美因茨形成两面夹击，炮兵开路；其复盘称第4回合在莱比锡全歼4个敌军，己方零阵亡。有效点是把多支部队的火力组织成同一轮歼灭，而非各自占地。
- de2 中期数次把装甲车送入前沿要塞，遭集中反扑，复盘称累计损失七八辆。说明本土火力优势也不能保证离开支援区后的先锋安全；占有工事不等于能够守住。
- de2 第10回合起改为让出平地、引敌离开要塞，再用交叉炮火打击，同时在后方建设工业。步兵诱饵与退让的价值在于改变敌军落点，使其进入己方可集中射击的位置。
- de1 的反击曾给对手造成压力，但未把局部打击转为持续优势。追击时必须重新检查后续炮兵、退路与敌方可见反击方向；不能因前方是弱步兵，就把机动主力送入其背后的火力场。
- 终局 de2 攻下汉堡，切断收入并击毁4级老坦克及指挥官，随后在汉堡就地造炮、占据空置工业区；第19回合攻下柏林，第20回合清理剩余领地。这里的收益来自同时削减老兵战力、收入和部署能力，不能只用占地数量评价。
- de2 自认对有防空的柏林使用两次空袭，仅造成17点伤害，耗费180金币、80工业；第一门炮买在维尔茨堡而非汉堡，影响到场速度；工业建设偏晚，多回合买不起坦克与炮兵。

## 转化为决策规则

### 诱饵与追击

设计诱饵要有可执行的后续火力，能控制敌军进入后的落点，且允许己方屏护部队撤离。诱饵是否成功看歼灭与交换收益，不看对手是否移动了一格。首都、财源和退路不得作为无法收回的赌注。

遇到弱步兵、残兵或主动让出的平地，先算追击结束位置：我方炮兵本轮和下轮能否支援，敌方可见炮兵及机动兵能否接力攻击，击杀后剩余行动力是否足够退出。信息不足时标为风险，不能把迷雾中的后排当成空地。可停在支援边缘、先炮击或换轴推进，不必为了人头追到底。

### 保留反击成果与老兵

集中反击后，重新比较下一轮可开火的部队和可补兵位置。若敌方还能用多方向炮火收回阵地，先整顿阵线；不要把一次漂亮的反击当成持续总攻的许可。健康前排保护火炮，步兵或装甲车压血，坦克在合法且可安全退出时收尾，利用击杀后的剩余行动力。

高等级坦克及指挥官难以用新兵立即替代。遭持续压血时及时轮换，预留撤退和当前规则允许的补给位置；避免与重要财源一起被包围，形成战力和经济同时崩塌。也不能为保一辆老兵放弃必守首都，按胜利条件取舍。

### 工业、前线部署与空袭

金币充足但工业不足时，提前评估工业投入与回本时间，不等主力损失后才解决造兵瓶颈。新夺取的前线城市或工业区确认合法部署与安全后，可就地造炮，比较它与后方购炮的实际到场时间；无法守住的新城不是安全生产点。

争夺汉堡这类支点时，综合看收入、工业、部署、敌老兵和后续路线。突破前留好守军与接应，避免新炮落地即被敌机动兵夺城。

有防空时先查看当前可见建筑及攻击预览，比较空袭伤害、金币与工业成本，以及是否能直接完成关键击杀或夺取目标。不要重复低收益空袭；必要时换炮火或地面进攻。此局浪费不构成“所有有防空的地块绝不空袭”的通用禁令。

这些规则仍受本国席位、战争迷雾、真实邻接、合法动作与当前补给规则约束。赛后全局复盘不能成为实战中读取敌方隐藏情报的授权。
