四角卡顿 · 逐项排查

每个按钮用一个开关进入游戏。方法：点开 → 正常打一场 → 盯着战斗刚结束那一两秒的四角 → 记下卡还是不卡。一次只试一个。

先做这两步定性：
① 先点 基准（当前修复版），打一仗看四角还卡不卡。
② 再点 对照·还原旧闪烁。如果这个明显更卡、而基准不卡 → 说明就是闪烁高亮的问题，已经修好。
若基准仍卡，再往下逐个试「关掉某一项」，哪个一关就不卡，问题就在那一项。
A · 定性对照
基准（当前修复版）
已把闪烁高亮做成缓存。先确认现在的表现。
打开
对照 · 还原旧闪烁 flashwarp
恢复到「每帧透视重画闪烁」的旧逻辑（我怀疑的元凶）。
打开
C · 3D 卡顿：地板（直接以 3D 打开；缩到最远、左右拖动到侧面领袖处最明显）
基准（当前版）
地板用 drawImage 按行拉伸（快路径）+ 缩小档位 + 跳过被桌子挡住的部分。
打开
地板用纹理填充 floorpattern
上一版的画法（CPU 渲染下每帧 60–120 ms）。用来对照。
打开
地板不用缩小档位 floornomip
远处地板直接从原尺寸贴图缩小取样。
打开
地板旧画法 floorold
每一行整行画（这次卡顿的来源）。用来对照。
打开
不画地板 nofloor
地板完全不画（极端对照）。
打开
不画墙 nowall
远处墙面不画。
打开
B · 关掉单项（哪个一关就不卡，问题在它）
不画闪烁高亮 noflash
战斗后我方地块闪烁的高亮层完全不画。
打开
不画单位光晕 noglow
去掉「可移动单位」的蓝色光晕。
打开
不画桌面摆件 noacc
桌上摆件（含兵人）的透视绘制关闭。
打开
不画顶层 notop
箭头 / 空袭范围圈等顶层不画。
打开
不画爆炸/飘字 noeffects
粒子爆炸和伤害飘字不画。
打开
不画四角 HUD nohud
四角面板/按钮完全不画。若这样就不卡 → 问题在 HUD 本身绘制。
打开
不画单位 nounits
地图上的单位不画（极端对照）。
打开
不画桌边领袖 nomarshal
三位领袖大图不画（这一版新增的每帧开销）。
打开
B2 · 细分「爆炸/飘字」（noeffects 命中后，这里精确定位）
只关爆炸粒子 noparticles
只关粒子，保留伤害飘字。
打开
只关伤害飘字 nofloats
只关飘字，保留爆炸粒子。
打开
粒子不重着色 notint
画粒子但不做逐帧按颜色生成画布（我最怀疑的 GPU 纹理churn）。若这样就不卡 → 就是它。
打开
粒子不叠加发光 nolighter
爆炸用普通混合代替 lighter 叠加（测是否叠加填充率过高）。
打开
C · 资源 / 填充率对照

关掉地面缓存（应该更卡，用于确认缓存有效）。
打开

打开
