01 · 这个版本和原版有什么区别

《总体战》沿用《世界征服者 2》的地图资源、地区制战场、基础兵种和卡牌战斗框架，在此基础上增加外交、指挥组织、重写的内置 AI、联机、沙盒创作和外部 Agent 对战。熟悉原版的玩家可以直接作战，但外交、补给、盟友借道和自定义战役目标值得先看。

阅读范围

本指南以已发布的 1.0.17 为基线，核对日期为 2026 年 10 月 6 日。沙盒国家失败条件、Mod 大厅及手机编辑适配已在 1.0.16 上线；手机框选退出修复已在 1.0.17 上线。更细化的欧洲新地图仍在制作，尚未作为正式地图发布。

  • 战役与征服：保留原版式玩法，并可在开局配置中调整战争迷雾、行动顺序、征兵等待、补给和外交背景。
  • 外交：战争、和平、同盟、互不侵犯、求和赔款、邀请盟友参战；部分模式还有国家稳定度与国家特性。
  • 军务：集团军、战区、指挥官与持续作战命令，减少大规模战场的逐兵操作。
  • 内置 AI：以总参谋部规划和指挥官执行为核心的规则 AI，处理前线、生产、经济、外交及跨海行动。
  • 沙盒：改国家、领土、兵力、外交，编辑事件、分支决策、胜负目标与连续战役，并保存、分享作品。
  • 个人素材库：管理图片，创建可复用的自定义兵种和卡牌，再选入战役。
  • 联机与桥对战：既可与其他玩家联机，也可把指定国家交给支持 WC2 MCP 的外部 Agent，甚至全席位 Agent 对战。
  • 更新：Windows、Android、iOS 和 Web 使用同一套发布资源，常规内容更新走签名热更新。

海军通行、移动范围显示、黑屏与触控布局的修复属于兼容性和操作修复。原版已经存在的移动、反击、基础兵种、基础卡牌等机制，不应全部算作本版本新增。

02 · 第一次玩，怎么选玩法

  1. 想直接体验：从首页进入战役或征服，选关卡与国家，在对局配置中确认规则。
  2. 想做一场德国对波兰、法国或苏联的战争：进入沙盒 → 经典战场，选择预设直接开始，或先编辑兵力和财政。
  3. 想创造自己的世界：进入沙盒 → 自由沙盒，用现成区域地图或“原版完整世界 · 跨关卡拼合”创建作品。
  4. 想和朋友一起玩：进入联机；沙盒作品也可从“我的作品”创建联机房间。
  5. 想和大模型对战：在对局配置 → Agent 席位接管里选择国家，复制接管指令给外部 Agent。

推荐的入门配置

先用常规地图熟悉移动与卡牌，再打开战争迷雾。第一次接触指挥系统时，先编一个集团军和一条明确的攻击或防御命令；第一次做沙盒时，先完成两国、一个目标、一个事件的小战役。

开局可调整的规则

  • 战争迷雾：限制实际可见的敌军情报。不要把旧侦察记忆当作当前驻军。
  • 行动顺序：选先手或后手，影响开局行动节奏。
  • 征兵等待：0～8 回合，限制新占领地区何时能够征兵；0 表示不额外等待。
  • 地区产出补给：决定补给卡恢复额度是否取决于地区金币和工业产出。
  • 停战赔款倍率：按对方在这次战争中的部队损失造价计算，倍率可调整。
  • 外交背景：在适用的征服局选择历史或自由；沙盒使用自由外交。

03 · 外交、稳定度和国家生存

关系不是固定阵营标签

外交开启后，各国之间有具体关系。战争允许交战；和平意味着当前不交战，但不等于同盟；同盟可以借道并提供协作与视野支持。互不侵犯是一种额外协定，不等于已经结盟。

结盟、求和、互不侵犯是提议，对方可能拒绝。不要把“已提交提议”理解为“对方必定同意”。宣战可能牵动其他同盟关系；邀请盟友参战也需要对方接受。

求和为什么会花钱

赔款基于对方在本次双边战争中损失部队的造价，再乘本局设置的倍率。是否能停战还取决于对方的接受判断、停战或提议冷却等规则。以外交面板实际显示的金额为准；部分结算允许欠款，金库不足不意味着赔款自动清零。

普通模式中的稳定度

稳定度代表国家内部维持战争的能力。主动开战、背盟、求和、首都失守和战争疲劳可能影响它；和平期间可以恢复。国家特性会调整部分代价，不能给所有国家套同一个扣分数字。

外交规则启用时，稳定度低于 80 后基础收入开始受影响：60～79 为 92%，40～59 为 80%，20～39 为 64%，低于 20 为 48%；部分国家特性可减轻惩罚。极低稳定度还可能带来财政流失等动荡。首都被敌国占领且稳定度降到投降门槛，可能导致国家灭亡；丢失首都与丢失全部领土不是同一个判定。

沙盒规则调整 · 1.0.16 起生效

沙盒已停用稳定度扣罚、低稳定度收入惩罚、动荡和自动投降。宣战、同盟、求和及赔款仍保留。各国是否灭亡由作者在“国家 → 本国失败条件”中设置；详见第 7 节。旧客户端需要更新到 1.0.16 或更高版本才能使用这项规则。

国家灭亡后会按游戏规则处理剩余领土、部队与编制，不只是把旗帜从列表里隐藏。玩家国家灭亡通常意味着战役失败；自定义目标不能让已经灭亡的玩家继续作战。

04 · 移动、盟友借道、补给和迷雾

移动看实际可达范围

单位的移动受行动状态、移动额度、地图邻接、陆海类型、驻军容量及外交关系约束。移动目标提示会显示本次额度内可达的多段路径目标，不只是紧邻地块。地图上看起来挨着，不一定意味着游戏数据中可直接通行。

1.0.15 修复了包括黑海附近在内的关卡海域缺失和部分海军通行问题，规则修复同时覆盖普通战役、征服、沙盒及共享规则的联机。关卡之外或作者主动移出战区的海域，仍不会自动开放。

盟友领土与领海可以借道

  • 盟友的空地块可以进入并停留。
  • 有盟友驻军的地块可在合法路径中经过，但不能在终点混编两国驻军。
  • 借道不会把盟友领土正式吞并。当地收入、首都与目标判定仍归原属国。
  • 你的驻军离开或全部损失后，地块恢复为盟友直接控制。
  • 如果后来与原属国开战，借道身份与占领关系会按新的外交状态处理。

因此，别只看驻军或临时显示的控制旗帜判断实际领土归属。判断收入与战役目标时，应看地块的真正所有国。

补给恢复的是一格的共享额度

打开“地区产出补给”后，补给用于有产出的己方陆地上的受损部队：额度为金币产出 × 2 ＋ 工业产出 × 5，一格共享，最高 250 点。不是格内每支部队各恢复 250 点。

关闭该选项时，使用固定的整格共享 200 点恢复规则。系统会分配恢复额度并处理部队已满血的剩余额度；补给不能理解为重新获得全部行动次数。补给卡本身仍受费用、目标合法性与冷却约束。

战争迷雾不是地图变暗这么简单

视野决定能读取哪些当前敌军数据与合法攻击情报。盟友提供的视野和侦察效果可以扩展信息；旧情报、事件投放的“未核实情报”不等于已确认敌军。攻击预测是评估值，实际结算后应重新看血量、驻军和可达范围。

05 · 集团军、战区和持续命令

除了逐支部队操作，本版本提供指挥组织。集团军把多支单位编在一起，战区组织多个集团军；指挥官与元帅提供相应的指挥和战术影响。一个集团军最多编入 16 个单位，其他编制上限以当前界面和本局配置为准。

怎样用才有效

  1. 先按战场方向或任务把单位编入集团军，避免把相距很远、任务完全不同的单位硬塞在一起。
  2. 选择可用指挥官，再把需要协作的集团军纳入战区。
  3. 给明确的任务：攻击、突破、合围、反击、防御、迟滞、集中、掩护、撤退、支援或全力作战。
  4. 在地图上选目标、路径或防线，设置优先级、风险与有效回合。
  5. 看执行状态和进度，战线变化后调整或撤销旧命令。

合围使用两条轴线；防御、掩护和迟滞可以围绕防线组织。路线必须由当前战区内可通行的相邻地块构成；不是在地图上画任意一条线就能穿越封闭地区。

有命令不等于保证完成

持续命令会尝试在后续行动中执行，但部队损失、道路被堵、外交变化、目标转移或风险过高都可能影响执行。把它理解为“交给指挥系统的任务”，不要理解为瞬间完成的技能。

玩家可选指挥官受国籍、年代、拥有或购买等限制；内置 AI 的指挥官分配不完全沿用玩家的购买流程。因此不能宣称双方所有指挥官获取条件完全相同。

06 · 内置 AI 到底是什么样的

默认内置 AI 是重写的 HQ 指挥系统，不是在线大模型。它在本地根据规则与战场评估决策；外部 Agent 对战则由另外的模型或代理通过 MCP 下令。普通单人局不需要为内置 AI 配模型 API。

它怎样组织一回合

  • 总参谋部规划：识别相连的接敌前线，评估双方力量、地区价值与威胁，选择进攻、防御和主要作战方向。
  • 组织与生产：分配指挥组织，安排征兵、建筑、经济投入及卡牌使用，兼顾眼前危险与后续收入。
  • 指挥官执行：结合当前局面逐步选择行动，行动后更新评估，处理进攻、支持、休整与调动。
  • 跨海作战：有专门的远征处理，包括寻找跨海作战机会、运输与沿岸行动，不只在陆地边界推进。
  • 外交判断：评估开战对象、力量对比、战争压力和提议接受概率，尝试求和、同盟或互不侵犯。

不同指挥官会有不同倾向

指挥官的攻击、防御与反击能力会参与进取、谨慎和纪律倾向的计算，使同一类任务不总是表现完全一样。这是规则模型中的倾向，不是会记住每位玩家性格、长期学习的真人式人格。

迷雾与公平性

战争迷雾开启后，HQ AI 使用所属国家的可见战局视图做规划；不能据此宣称它每一项决策都“像人类一样公平”或“从不犯错”。国家初始资源、兵力、特性、指挥官获取规则和战役配置本来就可能不同。

它使用启发式和估值，不是每步穷举所有未来回合的最优解。面对极端自定义数值、复杂事件链或特殊地形，可能保守、错估风险或执行不理想。想观察这些行为，可用托管或全席位 Agent/AI 观战；托管与外部 Agent 接管应明确区分。

怎么对付它

守住能征兵和产出的战略地块，控制补给与前线距离；用局部集中、海路和外交改变力量对比。只看全地图部队数量往往会误判，一个关键方向上的优势比总兵力数字更有用。

07 · 沙盒：从一张地图做出一场战役

入口和作品管理

沙盒菜单分为经典战场、自由沙盒、我的作品、Mod 大厅。经典战场常驻德国对波兰、德国对法国、德国对苏联三组预设；它们是便于开战和编辑的玩法方案，不是逐支历史部队的精确还原。

完整世界地图由原版跨关卡资源拼合，国家归属采用合成方案，可继续编辑。它与正在返工的“更细化欧洲地图”是两份不同资源，后者目前不属于已发布内容。

以地图为中心编辑

  1. 国家：添加或移除参战国，选择玩家国家，设置初始金币和工业。可把非玩家国家设为等待事件激活。
  2. 领土：先选国家再涂选；可增加、减少、转交领土，设为无主，或移出战区。转交会保留驻军，设为无主或移出战区会移除驻军。
  3. 部队：选择兵种或已选入的自定义兵种，再点本国地块直接部署。点已有部队可移动或移除。陆军部署到陆地、海军部署到海域，并受驻军容量约束。
  4. 外交：通过国家旗帜选择一对国家，设置开局战争、和平或同盟关系。
  5. 事件：用事件卡编辑条件、剧情与分支选项。
  6. 目标与连续战役：给战役设置玩法目的，再决定是否接下一章。

触屏上可收起操作面板，把空间让给地图；双指移动和缩放。需要指定目标领土时，用“在地图上点选多块”：再点一次取消，选完点“完成点选”。一组最多 64 块，支持全部满足或任一满足，无需记地块编号。

战役胜负目标

打开自定义目标后，会替代默认的消灭敌国胜利判定。胜利目标可选全部完成或任意完成；失败目标有任意一项满足即失败。还可设置完成时限，0 表示不限。

现有目标包括指定地块归属、连续坚守、护送指定部队、外交关系、国家灭亡、回合和事件完成。连续坚守按完整回合累计，中途失去控制会重新计数；护送绑定实际部队，不是随便一支同类部队。战斗中可打开“战役目标”查看进度。

各国失败条件 · 1.0.16 起支持

进入“国家”，选国家，再设置“本国失败条件”。默认失去全部陆地后灭亡；选择自定义后，用 1～32 项条件和“全部/任一满足”组合，替代默认的全部陆地丢失判定。玩家国灭亡仍导致战役失败。

例如：波兰在首都失守时失败；德国在第 20 回合且兵力已降至作者设定的门槛时失败；苏联在兵力降至某值且陆地数量低于门槛时失败。条件可用领土、兵力、资源、首都失守、外交和事件/决策记录；不能用“本国已经灭亡”反过来决定本国何时灭亡。

国家失败规则与整场战役失败目标分别设置：前者淘汰某个国家，后者直接结束玩家战役。沙盒稳定度停用后，旧作品中的稳定度效果不会再产生稳定度变化，旧稳定度低于门槛条件也不再触发，需要作者改成新的条件。

保存、撤销和分享

编辑会自动保存，也可手动“保存”；撤销/重做用来修正编辑操作。作品会出现在“我的作品”，可继续编辑、开始作战、复制、分享或删除。作品配置保存与战斗存档是两件事。

作品列表目前是本地保存。不要把登录账号理解为所有作品已自动跨设备云同步。换设备前先复制分享码留存；清理应用数据、浏览器数据或卸载可能影响本地内容。

08 · 剧情、事件条件和分支决策

通知与决策

剧情通知用于讲故事或自动施加效果；分支决策要求选择选项，不同选项可执行不同效果，并记录选择供后续事件或下一章读取。分支决策至少有两个选项。

不只按回合触发

  • 时间：回合达到、超过或等于门槛。
  • 外交当前状态：两国当前关系、国家正在战争中。
  • 外交历史变化：两国结盟后、指定或任意国家对某国宣战后、两国停战后。
  • 战场：地块现在归谁、地块曾被某国占领、首都失守、国家灭亡。
  • 实力：金币/工业、部队数量、陆地数量达到指定门槛。
  • 剧情链：前置事件完成、前置决策选了指定选项、继承上一章决策。

“当前两国结盟”检查现在的关系；“两国结盟后”记录开局之后实际发生过结盟。开局预设关系不会自动当作一场新发生的结盟事件。条件可以组合为全部满足或任一满足。

旧版作品可能保留国家投降与稳定度门槛条件；从 1.0.16 开始，沙盒停用稳定度与自动投降，这两类条件不再作为新创作入口。

能施加什么效果

金币与工业变化、外交改变、增援、部队治疗或伤害、领土转交、触发其他事件、区域侦察、投放未核实情报、延迟执行，以及国家入场或复国。效果可作用于地图点选的多块区域。自定义卡牌支持的效果是其中一个子集，不能把事件中的任意效果都当成卡牌可用效果。

一条容易理解的事件链

  1. “援助协议”：A 与 B 实际结盟后，给 A 增加工业。
  2. “边境警报”：C 对 A 宣战后，弹出决策，让 A 选择前线增援或财政动员。
  3. “援军抵达”：选了前线增援后，延迟若干回合生成指定部队。
  4. “停战谈判”：A 的兵力降到门槛且战争仍在继续时，触发谈判分支。

事件通常只触发一次。不要建立互相等待对方完成的前置循环；也不要用“第 5 回合等于”表达“第 5 回合以后随时可以”，后者应使用“不少于”。这是创作里最容易让事件永远不出现的两类错误。

09 · 素材库、自定义兵种与自定义卡牌

兵种和卡牌在素材库创建

进入沙盒 → 个人素材库，创建、编辑与管理兵种和卡牌，再选入具体作品。战役编辑器负责使用这些素材、部署部队和组织玩法；不必在每个战役里重复从零创建。

选入作品后，作品保存自己的定义副本。修改素材库中的模板，不等于自动把所有旧战役的数值改掉；这样可以避免一个模板改动破坏已完成作品。

自定义兵种的边界

以现有基础兵种为骨架，调整生命、移动、攻击与射程、伤害倍率、攻击模式、占领能力、击杀后移动特性、费用和图片等，自动生成对应征召卡。每个作品最多选用 64 种自定义兵种。

它是规则内的数据定义，不是上传脚本或导入一个全新的战斗引擎。陆海限制、容量和目标合法性仍生效。极端数值会明显改变平衡，也可能超出 AI 估值最适合的范围。

自定义卡牌

设置名称、类别、金币/工业费用、冷却、目标范围、条件、图片与效果。每张卡需要 1～16 个效果，每个作品最多选用 64 张自定义卡。治疗、伤害、增援、资源、外交、情报、事件触发和延迟等可组成不同玩法。

“购买”与“使用”分开：卡片商城购买东西不应弹出军事单位待选框；需要目标的卡牌在实际使用时才进入目标选择。选入卡牌后，仍要检查它的条件、目标和费用是否能在战役中满足。

图片空间与管理

  • 每个用户素材空间最多 30 MB；单张上传文件最多 4 MB。
  • 支持静态 PNG、JPEG、WebP。图片用于封面、兵种、卡牌或事件插图等。
  • 支持批量上传队列，单批最多 30 张，以及压缩、裁剪、预览、失败重试。
  • 用类别、标签、搜索和排序整理素材；管理引用、图片版本与批量清理。

素材库需要登录和网络。先裁剪、压缩再上传更省空间。上传素材本身不会使它自动出现在所有战役里，还需要在作品里选用。

图片版本更新可以更新受支持的本人本地引用；已经分享出去的作品会使用固定素材版本保护，避免作者之后更换图片导致别人拿到的战役悄悄改变。

10 · 分享、联机与连续战役

把作品发给其他玩家

  1. 在“我的作品”保存完成的战役，点“分享”。
  2. 复制完整分享码，发给对方；它通常以 WC2SB1 开头，较长是正常的。
  3. 对方进入沙盒菜单，点“输入分享码”，粘贴后点“解析分享码”。
  4. 核对名称、国家、地区和部队数量，点“保存到我的作品”。导入会创建新作品，不覆盖已有作品。

分享码携带配置，包括国家、领土、兵力、外交、事件和自定义定义；素材图片通过其固定资源引用取得，不是全部图片二进制都塞进分享码。使用带个人素材的作品仍需要能访问资源服务器。

分享的是战役设计，不是当前对局的完整战斗进度，也不是持续联机房间邀请。发送时保留完整文本；格式损坏、截断、客户端过旧或地图缺失都会影响解析。

Mod 大厅与作品布局 · 1.0.16 起支持

“我的作品”按战役卡片组织，支持最近编辑或名称排序；开始作战、继续编辑与共享放在主要位置，复制分享码、复制作品、联机与删除位于更多操作。

点“共享到 Mod 大厅”，登录账号、填写名称和玩法简介后发布。大厅展示作者账号、版本、国家和兵力信息；支持搜索、按最新更新或点赞数排序，并可点赞、取消点赞和保存到自己的作品。作者名由服务器根据登录身份确定，每个账号对同一作品最多计一个赞。

编辑本地作品不会自动改变大厅版本，需再次“更新共享作品”；同一作品更新保留原有点赞。取消共享会将作品从大厅移除，本地作品和别人已保存的副本保留。删除本地作品也不会自动取消大厅共享。

大厅中的作品可保存为本地副本，注明原作者与下载版本，然后编辑或开始游戏；它不是把其他玩家的作品变成可以直接覆盖原作者版本的编辑权限。每个账号最多发布 100 个作品，单份配置最多 8 MB；图片仍使用素材库资源和固定引用。

沙盒联机

从保存的作品创建联机房间，启用自定义内容。沙盒房间的人数受开局可用国家数限制，最多 4 人；其他国家可由 AI 行动。大家应更新到支持自定义内容的客户端，自定义沙盒联机要求 1.0.16 或更高版本，所有参与者应更新到兼容版本。

联机由服务器处理权威战局，不能只修改自己客户端的规则就要求其他玩家同步生效。房间超过 7 天没有实际继续游玩的活动会自动清理；不要把联机房间当作永久作品备份。

连续战役

把当前作品作为第一章，追加已保存作品作为后续章节，最多追加 8 章。胜利后进入下一章，可以选择继承资源、外交、部队损失状态和决策变量。

兵力继承只匹配下一章地图中仍属于同一国家的地块，不是任意把上一章所有部队重新放到新地图。国家或地图大幅变化时，作者应检查继承结果。连续战役目前用于单人玩法，不能当成已经支持完整跨章联机。

11 · 桥对战：让外部 Agent 控制国家

需要准备什么

需要运行中的游戏与对战桥，以及支持 WC2 MCP 工具的 Agent 客户端。单靠一个普通聊天窗口、把截图发给模型，不能获得实际游戏操作能力。Agent 使用 wc2-mcp-commander 的操作规则；对战桥通常位于电脑的 8651 端口。

玩家操作步骤

  1. 进入对局配置，打开“Agent 席位接管”。
  2. 开启接管，选要交给 Agent 的国家；可以选对手、盟国，也可以选玩家自己的席位。
  3. 点“检测桥”。电脑本机页面支持尝试自动启动桥；无法启动时，用“重试”或检查本机游戏服务。
  4. 为每个国家复制接管指令，粘贴到支持 WC2 MCP 的独立 Agent 会话。一个会话管一个国家，不要让两个会话抢同一席位。
  5. 回到对局配置并开始游戏。轮到被接管国家时，Agent 会收到本国战局、进行决策并提交。

全选国家可以进行全席位 Agent 对战；玩家进入观战。观战界面能看到的信息，不等于每个 Agent 获得的信息：Agent 仍应遵守所接管国家的战争迷雾。

手机连接电脑上的桥

手机里的 127.0.0.1 指手机自己，不能用它连接电脑。手机与电脑在同一局域网时，在“桥地址”填写电脑的实际局域网地址，例如 http://192.168.1.10:8651，确认端口可访问。上面的 IP 是示例，不要原样照填。

远程 Web 页面、HTTPS 页面与本地桥的连接，还受网络、证书和跨域限制。优先使用支持的本机游戏入口及其桥代理；“检测桥”成功后仍需真正开始并登记对局。

绑定一次，以后开新局怎么办

接管指令使用用户 ID ＋ 国家席位绑定。桥会把该用户最新的对战桥对局交给 Agent，新的 gameId 可以变化；通常不必每开一局重新发指令。

前提是原 Agent 会话仍在运行、桥服务可用、新局已启用该国家接管。换设备、清空浏览器数据或更换用户 ID 后可能需要重新绑定；新地图没有原绑定国家时，Agent 也不能自动改管别国。电脑重启或 Agent 会话终止后，需要恢复服务和会话，不能理解为永久无人值守。

Agent 每回合的正确循环

wc2_bridge_attach({ user_id: "WC2U-XXXXXX", country: "ru" })

// 绑定后循环：
wc2_bridge_wait_turn({ timeout_sec: 20 })
// 阅读最新快照、messages、view、units、tiles；
// 只操作 ru，并为每项操作填写真实中文 reason。
// 决策结束，使用刚领取的 turn_id 提交：
wc2_bridge_submit_turn({ turn_id: "本回合返回的ID", reason: "已完成本回合部署与攻击，提交行动结果" })
// 继续 wait_turn；gameOver 后也可继续等待新局。

这段是工具调用流程示意，不是玩家要输入游戏内的脚本。实际用户 ID、国家代码和桥地址，以游戏复制的接管指令为准，不要猜国家代码；不同地图可能使用不同代码。

  • waiting: true 表示还没轮到，继续等待，不代表工具坏了。
  • 每项操作填写具体中文原因，例如“集中炮兵削弱东线驻军”，不能用毫无内容的固定套话。
  • 不得控制其他国家，不得绕过迷雾读取隐藏部队；外交也要使用正常玩家可用流程。
  • 用桥的提交操作完成行动，不能拿普通 wc2_end_turn 替代。
  • 操作失败后取新状态，不要重复整批已产生副作用的命令，也不要提交过期回合 ID。

后台回放与最终战局

Agent 提交后，前端回放展示命令和说明，最终采用桥返回的战局快照完成同步。浏览器动画播放结果不是唯一裁判；动画与结果有差异时，会尝试采用提交结果同步，而不是直接把整回合判为失效。

当前回放增加了后台计时推进，不要求一直把窗口放在最前面。不过这不等于游戏已经搬到一个永久后台服务器上：浏览器被关闭、手机系统冻结应用、电脑休眠或断网，都可能中断前端推进与桥通信。

常见问题

  • 桥在线但没对局：确认游戏已经开始、启用了该席位并登记到桥；“端口在线”不等于“对局已经登记”。
  • 一直等回合：检查当前行动国家、用户 ID、国家代码与接管开关，确认该 Agent 会话没有退出。
  • 席位被抢占：检查是否有另一个会话绑定同一国，保留一个实际控制者。
  • 不同步或缺最终状态：先确认游戏与 MCP 使用兼容规则，重新领取当前回合；不要重放旧命令或盲目重启正常桥。
  • 手机连不上：检查电脑实际局域网地址、同一网络、端口和防火墙；别填手机自己的回环地址。

12 · 热更新、存档和版本边界

日常怎么更新

首页左下角可点击“检查更新”，交流群文字位于右上角。客户端拉取更新清单，校验签名，根据清单下载版本资源并校验文件哈希；完整资源准备好后切换到新的版本入口，再重新载入游戏。更新清单不是安装包，也不是只描述一句“更新到最新”的通知。

更新资源按版本保留，客户端可复用已经相同的资源。1.0.0n 可以直接更新到最新兼容版本，不用先装 1.0.11 再装 1.0.12。最新清单描述完整版本资源，因此中间版本的必要内容不会因为跳号就被漏掉。

应用壳与游戏资源是两层东西。页面、脚本、地图和图片等可热更新；原生更新插件、启动控制器或系统权限的问题可能需要一次覆盖安装。不能把所有原生问题都承诺用网页资源解决。

iOS 1.0.7 的特殊情况

针对旧版首页更新按钮无反馈的问题，另提供过一次 iOS 更新入口修复包。需要覆盖安装时，应保留原应用身份与原签名账号，避免先卸载导致本地内容丢失。这是旧壳修复的例外，后续日常内容仍以热更新为主；实际设备点击行为需以设备验证为准。

本指南的状态说明

  • 已发布：1.0.17。包含 1.0.16 的 Mod 大厅、沙盒国家失败条件、手机编辑适配、行动箭头与外交修复。

  • 尚未上线：更细化的欧洲地图仍在制作与调整。

  • 既有边界：作品主要本地保存；连续战役是单人功能；后台回放不能绕过系统休眠或冻结。

作品、战斗存档、素材库、联机房间与 Agent 绑定各有用途。需要长期留存作品时，保存配置并备份分享码；需要继续一场战争时保留战斗存档；素材空间只用于素材，不是无限云存档。
