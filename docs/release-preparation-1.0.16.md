# 1.0.16 发布准备记录

状态：签名热更新已发布，release 20261006051305；服务器与存储桶更新清单均已核验为 1.0.16。

- 新增沙盒 Mod 大厅：账号署名、搜索与排序、发布/更新/取消共享、点赞/取消点赞、保存本地副本。作者身份由服务器确定，同账号同作品只计一个赞；图片保留引用保护。
- 调整“我的作品”：战役卡片、编辑时间/发布状态、排序、主要操作与更多操作分组；本地删除和取消公开共享分开处理。
- 沙盒停用稳定度惩罚、动荡与自动投降；国家可使用全部/任一条件定义灭亡，支持领土、兵力、首都、资源、外交和事件条件；国家灭亡依赖不得循环。战斗目标面板展示已配置规则。
- 编辑类别、兵种及长条件/效果/目标列表改用下拉选择；国家多于四个时用紧凑选择器。
- 手机全屏画布样式限定主游戏画布，避免沙盒地图覆盖顶部栏；顶部栏固定层级，沙盒手机界面允许竖屏。
- 首页检查更新置于左下角，交流群1060198224置于右上角。
- 自定义沙盒联机要求1.0.16及以上，以保持前后端规则一致。

验证：改动模块语法检查、Mod数据库建表和SQL预编译检查、前端构建、后端归档；玩家指南在桌面/手机视口排版及目录链接检查通过。未运行游戏对局测试，未做安卓/iOS实机验收。现有构建中的重复escapeHtml成员警告不是本次引入。

原签名私钥已恢复并与客户端信任公钥核对一致；2496项资源上传完成，后端与Web入口已切换，健康接口与Mod大厅读取接口正常。另包含行动箭头仅指向相邻地块、自动参战保护条约、重复宣战保护战争账本的修复，11项外交规则回归检查通过。欧洲细化地图仍为独立产物，未集成。
